# Biplanes — инструкции для Claude Code

## Что это за проект

Дизельпанк-roguelike-survivor в Telegram Mini App. 2D side-view dogfight + Vampire Survivors-цикл билд-крафта. Современная переработка J2ME-игры BT Biplanes.

**Главный документ**: [docs/superpowers/specs/2026-05-21-biplanes-design.md](docs/superpowers/specs/2026-05-21-biplanes-design.md) — полная дизайн-спека, прочти прежде чем что-либо делать.

**Монетизация**: [docs/monetization-analysis.md](docs/monetization-analysis.md) — экономика, Stars, реклама.

## Профиль владельца

Сергей — продакт/контент-мейкер, **не разработчик**. Он не читает и не пишет код. С ним обсуждаем **продуктовые/игровые** решения (что чувствует игрок, как выглядит экран, какая фишка, какой арт). Технические решения (стек, структура папок, паттерны, либы, тесты) — принимаем сами с короткой пометкой «выбрал X потому что Y», без спроса деталей.

Никаких блоков кода, путей файлов и названий пакетов в чате с Сергеем. Это всё уходит в спеку и план реализации. В чат — только понятные ему сводки.

## Текущая фаза

**Прототип боёвки построен и играбелен, задеплоен** (gh-pages, ветка `feat/hud-animated-panel`, авто-деплой на push). Сделано: арена с раундами/волнами, stall-физика, ИИ (симметричный, с фиксом «врезается в землю»), билд-крафт ~25 модулей с редкостью, реальные подкрыльевые ракеты, шары-бонусы, погода/ветер, HUD (приборка/газ/патроны), меню с видео+музыкой, лого, кинематик-промты. История правок — в git и в памяти ([[project-combat-feel-decisions]]).

**Следующий большой шаг (обсуждён, ждёт «да» владельца): раздел 13 спеки — новый скелет билд-системы** (15 волн, одна жизнь, 14 пиков, 4 ветки + affinity-софт-специализация, кейстоуны, реролл/пропуск, босс на 15-й). Он *заменяет* XP-таймерную прогрессию из §3.
- **Рекомендация Claude (озвучена Сергею):** внедрять **поэтапно**. Сначала **скелет** (волны+одна жизнь+пик после волны 1из3+affinity+реролл/пропуск+босс-«Шрам») на **существующих** апгрейдах, разложенных по 4 веткам — чтобы дёшево проверить «кайфово ли». Потом наполнять **Бомбардира (зоны: напалм/газ/мины)** — главный новый геймплей+VFX — и кейстоуны/эволюции. Затем баланс по таблицам §13.4.
- **Открытое продуктовое решение:** Сергей ещё **не подтвердил** формат «15 волн, одна жизнь, босс» (это меняет арену с бесконечных раундов на тугой забег). Без его «да» скелет не начинаем.
- Мы уже на полпути: Штурмовик/Командир/Пассивка ≈ есть в текущих модулях; новое — система affinity+выдача пиков+волновой движок с боссом, и зоны Бомбардира.

## Принципы

- **Физика — фишка**. Stall-механика управления (как в оригинале BT Biplanes) — это то, ради чего всё затеяно. Калибровать на референс из репо TheRealPinkie/BT_Biplanes_src.
- **Headless core + тонкий рендер**. `packages/core/` — чистый TS без DOM/Pixi. Всё игровое состояние и физика там. `packages/render/` читает state и рисует.
- **Detrminism + replay**. Tick 60Hz, seeded RNG. Любой забег воспроизводим из `(seed, [commands...])`. Это основа для будущего multiplayer и анти-чита.
- **AI и игрок симметричны**. Оба эмитят `PlayerCommand`. Никакого разделения логики.
- **Тесты для физики обязательны**. Без них балансить roguelike — мука.

## Правила работы (наследуются от стиля Сергея)

- **Строить, а не покупать** — никаких no-code обёрток.
- **Код, не визард** — никакого drag-and-drop.
- **Claude Code-first** — основной интерфейс работы для Сергея.
- **Спрашивать, не выдумывать** — если что-то неясно по продукту, спросить Сергея. Технику — решать самим.
