### Вторая фракция «Алые Шакалы» (СВЕЖЕЕ, 2026-06-22) — в проде
- **Экран выбора фракции**: меню → Арена/Забег → оверлей с двумя вертикальными видео по краям (`assets/factions/faction_{sov,jackals}.mp4`), описание+пилот по центру, «Подтвердить». С.О.В. = прежняя игра (синий vs красные); Шакалы = **красный самолёт vs синие враги** + рукоятка-череп на леваре ГАЗа.
- **Самолёт Шакалов = «тяжёлый бугай»** (по типу KillZone Helghast vs ISA; С.О.В. — лёгкий скорострел, НЕ менять). Полный стат-блок: `docs/jackal-plane.md` + билд-пул: `docs/jackal-builds.md`. Ключевое: 240 HP, ×2 урон/выстрел, медленная пушка (крупные огненные ШАРЫ, «бум»-звук, кивок носа, отдача ×2.4), магазин 60, перезарядка 6с, ракеты мощнее, броня −20% входящего, скорость −10%, форсаж перегревается на 30% позже. **Парабола/дальность пуль ПОДОГНАНЫ под С.О.В.** (gravityScale = speed² → та же дуга, целиться так же). «Ведомый» = ОДИН ведомый (не рой). Все числа — именованные константы (`JACKAL_*` в shared, `RUN_JACKAL_*` в app).
- **Босс зависит от фракции**: С.О.В. дерётся со «Шрамом» (красный Барон), Шакалы — с ЧИКО (синий, ещё толще).
- **Шары**: 2-4/раунд, у Шакалов красные (Codex-арт), дроп: патроны/ремонт/скорострел/**«КАРТА»** (бонусный выбор карточки в бою).

### Лор-канон (зафиксирован в GDD.md §4)
С.О.В. = **Содружество Объединённых Видов** (аллегория свободного демократического общества). Алые Шакалы = карикатурные «имперцы»-пираты (аллегория фашизма). Отец Чико — пропавший без вести Ас (мотив мести). **Барон фон Клык на самом деле — хитрый ЛИС** (твист финала, арт не меняем). Пролог = играбельный детский налёт; миссия 1 = «выпускной в академии» = туториал (стрельба по шарам + бой с заблудившимся пиратом). Подробно — [[project-story-lore-drafts]].

### ⚠️ Зависания (читай перед правками рендера/цикла)
Две причины уже пойманы (см. [[project-second-faction]]): (1) **неограниченный `dt`** между кадрами → покадровые accumulator-циклы зависают (фикс: `dt` зажат ≤100мс); (2) **BlurFilter на masked-спрайте** валит рендер Pixi на части мобильных GPU (фикс: убран). Симптом «моторы крутятся, остальное замерло» = исключение в рендере. Теперь есть глобальный ловец ошибок + красная плашка **сверху по центру** + `localStorage['biplanes.lastError']`. **Превью НЕ крутит игру** (rAF замирает в фоне) — проверяй headless-тестами + ясным бутом + девайсом Сергея.

### Дальше (обсуждено)
**Мультиплеер** — ближайшая большая задача (детерминированное ядро под него подходит: один `tick`, реплей по `(seed, команды)`). Полиш фазы 2: глубже звук «бум» Шакалов, иконки карточек через Codex ([[reference-codex-image-generation]]), «Ведомый» со своим HP (исчезает при сбитии).

## Принципы

- **Физика — фишка**. Stall-механика управления (как в оригинале BT Biplanes) — это то, ради чего всё затеяно. Калибровать на референс из репо TheRealPinkie/BT_Biplanes_src.
- **Headless core + тонкий рендер**. `packages/core/` — чистый TS без DOM/Pixi. Всё игровое состояние и физика там. `packages/render/` читает state и рисует.
- **Detrminism + replay**. Tick 60Hz, seeded RNG. Любой забег воспроизводим из `(seed, [commands...])`. Это основа для будущего multiplayer и анти-чита.
- **AI и игрок симметричны**. Оба эмитят `PlayerCommand`. Никакого разделения логики.
- **Тесты для физики обязательны**. Без них балансить roguelike — мука.
