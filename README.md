# Biplanes

Дизельпанк-roguelike-survivor в формате 2D-dogfight для Telegram Mini App. Капитан Чико защищает скалы-анклавы парящего архипелага от воздушных пиратов. Современная обёртка над культовой J2ME-игрой BT Biplanes.

**Статус**: прототип боёвки v0.1 играбелен (2026-05-21). Дизайн-фаза завершена. Следующий шаг: фидбек владельца + калибровка физики, далее — обвязка база/кампания/TMA.

---

## Как запустить прототип

```bash
pnpm install
pnpm dev
```

Откроется на http://localhost:5173.

**Управление (десктоп):**
- `A` / `←` — поворот против часовой
- `D` / `→` — поворот по часовой
- `Space` — огонь из пулемёта
- `Shift` / `B` — бомба (пока заглушка-флаг)

**Управление (мобильный, landscape):**
- Левая нижняя зона — две кнопки поворота
- Правая нижняя зона — огонь и бомба

**Цель:** держись в воздухе, сбивай вражеские бипланы, набирай XP, выбирай улучшения. Самолёт постоянно норовит упасть — следи за тангажом и скоростью, как в оригинале.

## Что в прототипе работает

- Физика полёта со сваливанием — тяга, гравитация, потеря подъёмной силы при слишком крутом подъёме на низкой скорости
- Стрельба из пулемёта с cooldown
- Враги: лёгкие пираты-биплан, AI «преследует и стреляет когда в прицеле»
- Спавн волн с нарастающей частотой каждую секунду
- XP с убитых, level-up каждые ~20-30с, выбор 1 из 3 улучшений
- 10 базовых улучшений: урон, скорострельность, HP, магнит XP, дрон-ведомый, броне-бронебойные пули
- 1 эволюция: «Gatling» (Damage +50% + FireRate +50% = непрерывный огонь)
- Экран смерти со статистикой, кнопка рестарта
- Камера-преследование с шейком
- Параллакс-небо с силуэтами скал

## Что дальше

1. **Сергей запускает прототип** и играет 10-15 минут
2. **Решает**: «вкатывает или нет?» По трём критериям:
   - Чувствуется ли stall-физика как «вызов, который хочется освоить»?
   - Хочется ли после смерти жать «снова»?
   - Есть ли в выборе улучшений осмысленные решения?
3. Если ≥2 из 3 — двигаемся к полному vision (хаб → кампания → TMA-обёртка → монетизация). Если меньше — итерируем механику.

## Идея коротко

> 2D side-view, ландшафтная ориентация. Капитан Чико на биплане защищает дирижабли и скалы от пиратов. Каждая миссия 3-5 минут с физикой сваливания (как в оригинале). Между level-up выбираешь 1 из 3 апгрейдов, стакаешь и эволюционируешь — к концу миссии у тебя биплан-арсенал в стиле Vampire Survivors. После забега возвращаешься на свою базу-дирижабль, тратишь Lumen, открываешь героев, продвигаешь сюжет. 10 миссий кампании в 3 главах + endless.

## Архитектура (для следующих сеансов Claude Code)

Монорепо pnpm. Headless физика в `packages/core/` (чистый TS, без DOM/Pixi — ESLint этого следит). Рендер в `packages/render/` (PixiJS 8). Ввод нормализуется в `packages/input/` в `PlayerCommand`. AI-боты эмитят такие же `PlayerCommand`, так что симметрично с игроком. `packages/app/` оркеструет всё в game loop. `apps/web/` — Vite-обёртка для браузера.

Подробнее в [CLAUDE.md](CLAUDE.md) и в плане.
