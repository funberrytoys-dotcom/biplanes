# Забег — новая система перков (32 перка): статус реализации

Ветка `feat/perks-32-rework`. Точка отката: тег **`pre-perks-rework-backup`** (состояние до работ).
В игре переключатель: `?perks=old` в URL или `localStorage['biplanes.newPerks']='off'` → возврат к старому пулу.

## Что сделано (реально, с тестами)

- **Каталог 32 перков** (`packages/core/src/run/perks.ts`): 12 С.О.В. + 12 Шакалы + 8 Общих, фракция/категория/тир/редкость/предки/синергии/стартовые ядра/порог волны/иконка.
- **Редкость (твои 5 цветов)** по тиру: Деталь→🟢 обычный, Модуль→🔵 редкий, Узел→🟣 эпический, Легенда→🟡 легендарный; Феникс и Захват целей → 🔴 мифический.
- **Выдача/гейтинг** (`perk-pool.ts`): частота по редкости + гейт по фундаменту (предки) + порог волны + **гарантия рецепта** (заслужил корону — придёт). Имба не падает на старте.
- **Стартовое ядро**: экран выбора после фракции, ядро даётся бесплатно и открывает ветку.
- **Синергии**: показаны на карточке (подсветка владения) + горстка явных бонус-связок дают реальный эффект.
- **Механики** (`apply-perk.ts`): каждый из 32 перков реально меняет бой. Детерминизм и стабильность сохранены (без новой пер-тик логики, без новых полей в реплей-пути).
- **Иконки**: 32 PNG в `apps/web/public/assets/run/perk-icons/`, грузятся в карточки.
- **Откат**: старый пул/экран не тронуты; флаг переключает.
- **Тесты**: 35 новых (каталог, гейтинг, механики, run-state, полный 15-волновой забег обеих фракций). Весь сьют ядра зелёный (**294 теста** + 35), включая freeze-hunt и детерминизм. Тайпчек + прод-сборка проходят.

## Реестр фиделити (честно: что «по-настоящему», что приближение)

«Приближение» = перк реально влияет на бой через существующий модификатор, но фирменная
б­еспок-механика из спеки — это следующий заход углубления. Локальная замена, не переделка.

### Реализовано близко к спеке (реальная механика)
Спаренный ствол (веер), Осиное гнездо (дроны), Жало роя (+рой), Ремонтный дрон (реген),
Полный рой (5 дронов), Звено асов (живой ас-ведомый), Напалмовый ковёр (огнехвост),
Гром-пушка (пробитие/тяжёлая пушка), Двустволка-картечь (веер+хвост), Бронепластины (+HP, стак ×3),
Полевой ремонт (реген), Броненос (HP+броня−скорость), Таранный киль (переживаешь таран).

### Приближение (стат-замена; бесспок-система — в следующий заход)
| Перк | Сейчас | Полная версия требует |
|---|---|---|
| Раскрутка | +темп флат | накопительная раскрутка + каждый 6-й двойной |
| Трассирующий замок | +урон флат | система меток на цели |
| Радиатор-турбина | +темп флат | связка темпа со скоростью |
| Гатлинг-шторм | постоянный бурст | оконный спец на пике раскрутки |
| Осиный залп | самонавод+быстрый залп | 6 микро-ракет веером |
| Перезалп | быстрый залп | триггер на чистом выходе из срыва |
| Бритва | +манёвр(буст) | поле угловой скорости/инерции |
| Домна | +урон флат | шкала жара 0–100 как ресурс |
| Перегрев=залп | +урон флат | авто-выброс на 100 жара |
| Чугунный гостинец | +урон/откат | одна тяжёлая ракета по дуге |
| Ипритный колокол | +урон флат | зона уязвимости |
| Огневой приказ | +урон флат | фокус-приказ звену |
| Братская броня | −вход. урон флат | броня по числу живых асов + ярость |
| Феникс | реген/HP | детерминированный 1 второй шанс (нужно поле revive) |
| Чистый срыв | +буст | рывок на чистом выходе из срыва |
| Эгида | −вход. урон | щит на 1 удар |
| Дымзавеса | −вход. урон | срыв lock + облако дыма |
| Мёртвая петля | быстрый залп | сброс кулдаунов на чистой петле |
| Захват целей | самонавод+урон | тайм-фриз + мульти-таргет (тех-флаг, в самый конец) |

Ветка «Пилотаж» (Чистый срыв/Перезалп/Эгида/Дымзавеса/Мёртвая петля) держится на распознавании
чистого выхода из срыва/петли — это общий новый детектор поверх stall-физики, главный кандидат
на следующий заход и калибровку «на ощупь» на устройстве.
