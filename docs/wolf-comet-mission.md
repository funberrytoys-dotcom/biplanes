# Миссия «Волчья комета» — дизайн + план реализации

Кампанейский уровень: **С.О.В. (синий игрок) уничтожает дирижабль-носитель Алых Шакалов «Волчья комета»** и все истребители, что он выпускает. Эпичный по масштабу босс — летающий линкор-левиафан.

> Статус: **фундамент готов** (арт + протестированный движок босса + этот план). Игровая обвязка (новый режим + рендер) — следующий шаг, ставится скрытым флагом `?mission=wolfcomet` для плейтеста, потом включается в меню кампании. Сергей плейтестит ощущение/масштаб (превью не крутит игру — визуал докручиваем по его фидбэку).

## Концепт
- **Левиафан = объект в мире, видимый по частям.** Камера показывает экран; игрок летит вдоль туши (~2.5-3 экрана). Дирижабль медленно дрейфует.
- **Не один хитбокс — секции.** Бортовые **турели** (стреляют по тебе), **двигатели** (кормовые винты) и **ЯДРО** (рубка-мостик). Ядро неуязвимо, пока живы турели и движки → сначала «раздеваешь» корабль, потом добиваешь рубку = победа.
- **Носитель выпускает истребители** (биплан-Шакалы с палубы) волнами — их тоже надо сбивать.
- **Эпичность:** огромный силуэт, ряды стреляющих турелей, волны истребителей, драматичное разрушение по секциям, финальное падение в огне.

## Арт (готов / нужно)
Готово (в `apps/web/public/assets/airships/new/`, прозрачный фон, боковой вид):
- `wolf_comet_carrier.png` — **корпус** (баллон-зеппелин + линкор-гондола, голова-волк-таран, эмблема, ряд пушечных портов, рубка, палубные бипланы, винты). Основной спрайт.
- `wolf_comet_turret.png` — **турель** (двуствольная пушка) — отстреливаемая цель, кладётся поверх корпуса в позициях секций.
- `wolf_comet_sideview.png` — альтернативный корпус (запасной).

Можно догенерить (Codex, по желанию): отдельный **двигатель/винт**, **повреждённая турель/обломок**, **горящая секция** для состояний разрушения. Пока — взрыв из существующей системы FX.

## Движок босса (готов, протестирован) — `packages/core/src/run/wolf-comet.ts`
Чистый детерминированный модуль (8 тестов):
- `createWolfComet(x,y,width,height)` — строит секции: **6 турелей** (нижний ряд гондолы), **2 двигателя** (корма), **1 ядро** (рубка). Позиции — доли габарита (0..1), не зависят от разрешения.
- `stepWolfComet(c,dt)` — дрейф + кулдауны турелей.
- `damageWolfCometSection(c,id,dmg)` — урон; **ядро неуязвимо до coreExposed** (все турели+движки мертвы); `defeated` = ядро мертво.
- `wolfCometSectionWorldPos`, `wolfCometTurretsReadyToFire`, `wolfCometTurretFired`, `wolfCometHealthFraction` (для HUD-полоски).
- Баланс-константы (тюнятся): турель 220 HP, движок 320, ядро 2600, интервал огня турели 1.6с, дрейф 26 px/с.

## Как обвязать в игре (следующий шаг)
Переиспользуем пайплайн «Арены» (он уже даёт игрока, камеру, спавн врагов, HUD, победу/поражение). Ключевой трюк: **секции = неподвижные «враги»**, приколотые к движущемуся корпусу:
1. **Режим** `runMode='wolfcomet'` (старт по `?mission=wolfcomet`, изолированно — не трогает Арену/Забег).
2. **Корпус** — большой спрайт, ползёт по миру (`stepWolfComet`), синкается каждый кадр.
3. **Секции-цели** — на каждую турель/движок/ядро ставим стационарную сущность-«врага» со спрайтом турели и HP секции, позицию приколачиваем к `wolfCometSectionWorldPos` каждый кадр. Попадания пуль игрока → урон секции (готовая коллизия пуля-самолёт), смерть → взрыв (готовый FX).
4. **Турели стреляют** по игроку (готовая система вражеского огня), когда `wolfCometTurretsReadyToFire`.
5. **Истребители** — волнами с палубы (готовый спавн врагов).
6. **Победа** = `defeated` (ядро добито) → экран триумфа. **Поражение** = игрок сбит.
7. **Камера/HUD** — босс-полоска (`wolfCometHealthFraction`), маркеры секций, широкий зум для масштаба.
8. Когда Сергей подтвердит ощущение — **кнопка миссии в меню кампании**.

## Что проверить Сергею (плейтест по скрытой ссылке, когда обвязка будет)
Масштаб (достаточно ли огромный), читаемость секций, темп «раздевания» корабля, плотность истребителей, HP-баланс (эпично, но проходимо), драма разрушения. Всё — именованные константы, правлю точечно.
