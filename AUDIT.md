## 🔴 ВЫСОКИЙ ПРИОРИТЕТ

### A1. Живой `BlurFilter` на занятом FX-слое — поверхность мобильного фриза
`packages/render/src/scene/glow-layer.ts:16-17`. `BlurFilter` висит на `glowLayer.container`, куда сыплются ВСЕ аддитивные частицы (DamageFx до 48 шт + перерисовка/кадр, вспышки дула, трассеры — `main.ts:1196-1198`). Это ТОТ ЖЕ класс краша, что уже ловили (masked-emblem BlurFilter убран в `a6aa08a`), но **отдельный, уцелевший** фильтр. Фильтр заставляет Pixi рендерить во вне-экранную цель размером со слой каждый кадр — на части мобильных GPU это бросает исключение → видимая игра замирает (rAF продолжает крутиться). **Сильный кандидат на «моторы крутятся, остальное замёрзло».** Починка = УБРАТЬ фильтр (аддитивный блендинг детей сохраняется), это согласуется с защищённым решением «BlurFilter не возвращать», а НЕ нарушает его. ✔Верифицировано.

### A2. Дебриф «Забега» у Шакалов показывает сырой `wingman` и чужие названия
`packages/core/src/run/run-summary.ts:31-47`. `buildRunSummary` строит названия из `UPGRADE_DEFS` (тексты С.О.В.) и метки из `BRANCH_LABEL` (ветки С.О.В.), без параметра фракции. Для Шакалов: карты показывают названия С.О.В. («Тяжёлые БЧ» вместо «Железный дождь»), ветки — «Штурмовик» вместо «Налётчик», а сигнатурная карта `wingman` (её нет в `UPGRADE_DEFS`) выводится как сырой токен **«wingman»** (фолбэк `?? id`). `endRun` (`main.ts:2277`) фракцию не передаёт. Чисто отображение (не баланс). ✔Верифицировано: `FACTION_BRANCH_LABEL`/`factionUpgradePool`/`WINGMAN_DEF` готовы в `faction.ts`; `chosenFaction` в области видимости `endRun`. **Бонус:** чинит и находку «`FACTION_BRANCH_LABEL` — мёртвый экспорт» (станет используемым).

### A3. (test-gap) Спасительная логика ИИ от земли — без тестов
`packages/core/src/ai/chase-policy.test.ts`. Покрыт только legacy-`chasePolicy`. ## 🟠 СРЕДНИЙ ПРИОРИТЕТ

### B1. `explosionEvents` растёт безгранично весь забег (утечка памяти + O(n) копия 60×/сек)
`packages/core/src/world/tick.ts:919,1375`. В отличие от других пер-тиковых буферов событий (заменяются каждый тик), `explosionEvents` копируется вперёд через spread и только дополняется, никогда не очищается. Рендер маскирует симптом водяным знаком `prevExplosionEventCount` (`main.ts:3201`), но ядро реально течёт и копирует всё длиннее. Детерминизм не страдает. Починка: в tick начинать с пустого массива; в `main.ts` итерировать все события тика напрямую (убрать водяной знак в 4 местах). ✔Верифицировано: `tick.test.ts:237/640` (len 1 / 0) остаются зелёными. `certain`.

### B2. X-обёртка координат — одиночный `if`, не устойчива к большому смещению
`packages/core/src/physics/plane-physics.ts:169-170` и `pilot-physics.ts:48-49,126-127`. `if (px<0) px+=W` оборачивает максимум на одну ширину мира. На скролл-картах (W>2000) boundary-wind добавляет ±1500·dt к vx, при dt до 100мс + пикировании теоретически выносит за >1 ширины → кадр самолёт вне мира. Маловероятно при текущих кэпах, но латентная дыра, чинится тривиально (modulo).

### B3. Портрет диалога: деление на размер текстуры до загрузки → scale = Infinity
`packages/app/src/campaign/dialogue-overlay.ts:127-132`. `Sprite.from(url)` затем сразу `118/Math.max(w,h)`; при кэш-промахе/упавшем прелоаде w=h=0 → scale=Infinity, портрет битый весь диалог (Pixi не перефитит после догрузки). Сейчас работает только т.к. портрет Чико прелоажен. Починка: задавать явный размер (как делает экран итогов).

### B4. Залипание клавиш при потере фокуса окна
`packages/input/src/keyboard.ts:8-13`. Зажатые W/A/D/Shift при alt-tab остаются в Set навсегда (keyup не приходит) — самолёт продолжает рулить/газовать сам. Нет ни одного `blur`/`visibilitychange`-хендлера. Починка: `blur → keys.clear()` + снятие в destroy.

### B5. Спрайты врагов/пилотов снимаются, но не уничтожаются (утечка GPU-геометрии)
`packages/app/src/main.ts:3533-3540,3554-3558,3687-3696`. На исчезновении id вызывается `removeChild` + `Map.delete`, но не `destroy` — фабрики `createPlaneSprite/createPilotSprite` его не предоставляют. id монотонны → Map не переиспользуется → за длинную сессию геометрия копится. Починка: добавить `destroy()` фабрикам + звать в 3 местах (и `resetToMenu`).

### B6. (deadcode) `spawn-system.ts` — весь модуль мёртв
Импортируется только собственным тестом; живые враги спавнятся через `arena-waves`/run-логику. Латентный риск зависания, если когда-то подключат с большим dt. **Может быть запланированный режим «свободная охота»** → продуктовый вопрос, в TODO (не удаляю вслепую).

### B7. (deadcode) `body.ts:234` `usesFullSpriteArt=true` хардкодом → весь рисованный fallback мёртв
Все `!usesFullSpriteArt`-ветки в `plane-sprite/index.ts` мертвы; рисованный самолёт строится с alpha=0 и не показывается. Лишние аллокации/draw на ~8 самолётов. Срезать рискованно (большой объём) → TODO-чистка.

### B8. (deadcode) `run-flow.ts` — `resolveRunFlow` тестируется, но в игре не подключён
Хорошо покрытая стейт-машина забега не используется: `main.ts` реализует прогрессию своим кодом. Тесты дают ложную уверенность. Подключение = риск изменить геймплей → TODO (архитектура). Парная мелочь: `run-state.advanceWave`/`RunState.wave` тоже только в тестах (`runSession.wave` остаётся 1 до перезаписи в `endRun`).
