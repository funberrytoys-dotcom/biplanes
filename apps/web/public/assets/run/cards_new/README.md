# cards_new — образцы иконок карточек билд-крафта (НА УТВЕРЖДЕНИЕ)

Сэмпл-набор иконок модулей «Забега», сгенерён через Codex (`image_generation`) в фазе 4 авто-прохода. **По одной на каждую из 4 веток** — чтобы Сергей оценил СТИЛЬ, прежде чем гнать полный набор (~25 шт).

| Файл | Ветка | Карта-образец |
|---|---|---|
| `card_armor_piercing.png` | Штурмовик | Бронебойные ленты |
| `card_incendiary.png` | Бомбардир | Зажигательная смесь |
| `card_wingman.png` | Командир звена | «Ведомый» |
| `card_hull_plating.png` | Корпус и сила | Усиление корпуса |

- 512×512, **прозрачный фон (alpha)** — кладутся поверх цветной карточки.
- Стиль: дизельпанк, латунь/сталь/охра, тёплая палитра, читаемая иконочная форма.

**НЕ подключены в UI.** Экран level-up сейчас рисует ветка-эмблему ватермаркой (`assets/run/emblem_*.png`) — это не тронуто. Если стиль ОК:
1. догенерить остальные ~21 карту в этом же стиле,
2. подключить в `packages/app/src/screens/level-up-screen.ts` (отдельная задача — это геймплейный UI).

Старый арт не перезаписан. Полный список карт — `docs/jackal-builds.md` / спека §13.
