# 3D → спрайты

Конвейер, который берёт 3D-модель самолёта из Tripo, чинит её и **запекает
спрайт-лист** в том же формате, который движок уже читает. Игра остаётся 2D —
меняются только картинки.

## Что даёт Tripo, а что нет

Tripo отдаёт **один цельный меш** — ни костей, ни отдельных деталей, ни
анимации. Проверено на всех одиннадцати `.glb` и на `.fbx`: везде один объект,
ноль арматур, ноль экшенов. Элероны, руль высоты и руль направления там
нарисованы на общей скорлупе. Поэтому «взять готовую модель с рабочими рулями»
нельзя — таких генераций не существует, и разрезать меш с навеской костей
придётся при любом раскладе.

Из двенадцати генераций текстура есть у трёх; остальные — белые болванки.

## Зачем

Раньше каждый ракурс и каждая фаза анимации рисовались вручную. Теперь модель
крутится в Blender и лист собирается кнопкой: новый ракурс — сдвинуть камеру,
новая раскраска — поменять материал, перепечь весь комплект за пару минут.

## Что чинит конвейер

Tripo собирает модель из наших ортографических рендеров и стабильно ошибается
в одних и тех же местах:

- **Винт.** Главная беда не в форме, а в том, что винт приварен к тому же
  единственному куску, что и весь самолёт: крутиться он не может в принципе.
  Конвейер вырезает его и ставит отдельным объектом на ось — честный
  двухлопастный по канону (дерево + золотые законцовки), с полупрозрачным диском
  ометания. Форма у Tripo вышла по-разному: ранние генерации («vintage biplane»)
  лепили крест из четырёх лопастей — горизонтальную пару с вида спереди плюс
  вертикальную с вида сбоку; те два варианта, что мы взяли в работу, отдали
  нормальные две лопасти. Проверять углы лопастей — гистограммой по секторам,
  не на глаз.
- **Морда мотора.** Внутри капота остаются рваные грани. Ядро вырезается,
  ставится тёмный задник и латунная крышка картера; цилиндры остаются на месте.
- **Крылья сверху.** Текстура ложится кляксами. Плоские поверхности крыльев и
  стабилизатора перекрашиваются канонической заливкой (С.О.В. — синий, Шакалы —
  чёрный); расшивка, окантовка и фюзеляж остаются с текстурой Tripo.
- **Пулемёты.** Висят над палубой — конвейер сажает их на фюзеляж и добавляет
  подставку.

Плюс вешает риг: элероны на всех четырёх консолях, руль высоты, руль
направления. Меш разрезан по линиям шарниров, привязка жёсткая — каждая
поверхность поворачивается целиком, как отдельная панель, а не гнёт обшивку.

## Управление: одно правило

Нос смотрит в +X, верх в +Z, значит **+Y — левое крыло пилота**.

Положительный угол = **ручка вправо / ручка на себя / правая педаль**. Для
элеронов знак берётся из `CONTROL_SIGN` в `plane_pipeline.py` — кости зеркальны,
поэтому один угол уже даёт дифференциал, а знак разворачивает этот дифференциал
в ту же сторону, куда уводит руль направления. Без него крен шёл влево, а
рыскание вправо, и вираж получался нескоординированным.

Проверка после любой правки рига:

```bash
python tools/3d/blc.py tools/3d/verify_controls.py
```

Скрипт отклоняет каждую поверхность на всех трёх самолётах и печатает `ALL PASS`
либо называет ту, что пошла не туда: левый элерон вниз и правый вверх при ручке
вправо, руль высоты вверх при ручке на себя, руль направления вправо при правой
педали.

## Как запустить

Blender открывать не надо: `blc.py` запускает его в фоне. Плейсхолдеры вида
`%TAG%` подставляются парами `КЛЮЧ=значение` прямо в командной строке.

Сцены, рендеры и запечённые кадры живут в папке `.3dwork` в корне репозитория
(она в `.gitignore`). Путь можно поменять переменной `BIPLANES_3D_BASE`; сами
скрипты всегда читаются из этой папки, так что временная папка сессии больше ни
при чём.

```bash
# 1. собрать модели: починить нос, винт, крылья, повесить риг
python tools/3d/blc.py tools/3d/run_plane.py TAG=sov
python tools/3d/blc.py tools/3d/run_plane.py TAG=jkl
python tools/3d/blc.py tools/3d/run_plane.py TAG=jkl2

# 2. добавить полупрозрачный диск ометания (сразу всем трём)
python tools/3d/blc.py tools/3d/add_disc.py

# 3. проверить риг
python tools/3d/blc.py tools/3d/verify_controls.py

# 4. запечь по 50 кадров 512x310
python tools/3d/blc.py tools/3d/bake_sheet.py TAG=sov

# 5. склеить атласы 5x10 и положить в public/assets/biplanes
python tools/3d/compose_sheet.py

# 6. перенести координаты кабины и границы блоков в body.ts
python tools/3d/patch_game.py

# 7. (по желанию) демо-ролик: винт + проверка рулей
python tools/3d/blc.py tools/3d/demo_video.py TAG=sov
```

## Формат листа

512×310 на кадр, 50 кадров, сетка 5×10 → 2560×3100, палитра 200 цветов,
около 650 КБ. Самолёт смотрит **влево** — движок сам зеркалит.

## Как посмотреть в игре

`?art=3d` — включить запечённый арт, `?art=classic` — вернуть нарисованный.
Выбор запоминается.

## Формат листа: сетка поз, а не анимация

Лист самолёта — не мультик, а **таблица поз**. Ничего на планере не движется
само: качку, винт и пилота рисует движок. Строки — крен (девять положений от
−22° до +22°, шаги сгущаются возле нуля, где живёт лёгкое покачивание), столбцы —
руль высоты (ручка на себя / нейтраль / от себя). Кадр = `строка × 3 + столбец`.
Итого 27 кадров, 512×400, сетка 6×5.

Крена в физике нет — игра сайд-вью, разворот идёт петлёй. Крен тут чисто
косметический: самолёт без него читается как картонка. Ограничен 22°, а
удерживаемый наклон в вираже — 13°, потому что дальше верхнее крыло начинает
закрывать кабину с пилотом.

Винт печётся **отдельным листом** с той же камеры: десять чётких положений
лопастей на полоборота и три смазанных кадра для быстрого вращения. Сбоку диск
винта виден с ребра, поэтому «быстро» — это узкая полупрозрачная линза, а не
круг. Движок выбирает кадр по газу (`prop-spin.ts`), крутит быстро, а
останавливает медленно, на выбеге.

## Что не доделано

**Синие подтёки на золотой окантовке хвоста С.О.В. — вылечено.** В
`metalize_trim` есть ручная разметка зон: список коробок, внутри которых грань
судят не по строгому тесту, а по средней краске с ослабленными порогами. Для
С.О.В. таких коробки две — киль (выше фюзеляжа) и стабилизатор (снаружи от
него), так что кремовая полоса по борту в них не попадает и цвет не теряет.
Коробки надо рисовать ТЕСНО: ослабление порога на весь самолёт разгоняет золото
по фюзеляжу.

**Пилот в кабине не кренится вместе с самолётом.** Бюст — плоский спрайт, он
едет за кабиной по вертикали (таблица `bob` считается по позам), но сам остаётся
прямым. На 22° это почти не видно; если понадобится — печь бюсты по позам.

**Камера — 0° вбок, 3° вверх.** Выше поднимать нельзя: верхние крылья ложатся
плитой на фюзеляж и закрывают кабину. Проверено рендерами 8/10, 4/6, 0/4, 0/2,
0/0.
